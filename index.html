About

Built for indie authors.

Authorly is a small, growing collection of free tools for self-published authors. No accounts. No upload-your-manuscript. No paywalls on the basics. Just tools that work.

Powered by Anthropic''s Claude — the AI we found gives the highest-quality output for craft work like this. Authorly calls the Claude API directly from your browser using your own API key (free signup at console.anthropic.com, around $0.01 per search). Your key stays in your browser - we never see it.
